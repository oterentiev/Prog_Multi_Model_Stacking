# Dataset

This project uses the **Elliptic Bitcoin Dataset**, which is publicly available through Kaggle.

The dataset is **not included** in this repository due to its distribution policy.

## Download

The dataset can be downloaded from:

https://www.kaggle.com/datasets/ellipticco/elliptic-data-set

## Required Files

After downloading, place the following files into this directory (`data/`):

```
elliptic_txs_classes.csv
elliptic_txs_features.csv
elliptic_txs_edgelist.csv
```

The final directory structure should look like

```
Prog_Multi_Model_Stacking/
│
├── data/
│   ├── elliptic_txs_classes.csv
│   ├── elliptic_txs_features.csv
│   └── elliptic_txs_edgelist.csv
```

Once the files are placed in this directory, the notebook can be executed without modifying any file paths.
